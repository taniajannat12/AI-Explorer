# 🤖 AI Explorer

AI Explorer is a React-based web application where users can explore AI tools, view details, browse categories, and analyze AI-related data.

## ✨ Features

* 🏠 Home page
* 🤖 Explore AI tools
* 📄 AI details page
* 🗂️ Categories
* 📊 Analytics
* 🛒 Cart functionality
* 🔄 Loading screen
* 🔔 Toast notifications
* 🧭 React Router navigation
* 📱 Responsive design

## 🛠️ Technologies

* React.js
* JavaScript
* React Router DOM
* Tailwind CSS
* React Toastify
* Vite

## 🚀 Run Locally

```bash
git clone https://github.com/your-username/ai-explorer.git
cd ai-explorer
npm install
npm run dev
```
